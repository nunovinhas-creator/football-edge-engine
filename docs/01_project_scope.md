# Football Edge Engine

## Project Scope

### Vision

Football Edge Engine is a quantitative research platform designed to identify positive expected value (+EV) betting opportunities in football.

The project does not aim to predict match winners.

Instead, it aims to estimate the true probability of football events and compare it with market odds to identify pricing inefficiencies.

---

## Philosophy

The project is based on five principles:

1. Football is a dynamic system, not a static average.
2. Market prices are not always equal to true probabilities.
3. Feature engineering is more important than complex algorithms.
4. Every model must be explainable.
5. Decisions are evaluated by long-term ROI, not prediction accuracy.

---

## Initial Markets

The first version of the project will focus on:

- Corners
- Shots
- Cards

Goals and Match Odds will be added later.

---

## Data Sources

Current data source:

- Bzzoiro Sports API

Future sources may be added if they provide additional value.

---

## Success Metrics

The project will be evaluated using:

- Expected Value (EV)
- Return on Investment (ROI)
- Yield
- Closing Line Value (CLV)
- Drawdown

Prediction accuracy is **not** the primary objective.

---

## Development Strategy

The project will be developed incrementally.

Each new feature must satisfy:

- Football hypothesis
- Mathematical definition
- Implementation
- Historical validation

Only validated features become part of the production model.
